# Альфа Защита — распознавание синтезированной речи

Модуль определяет по фрагменту речи длиной 3 с, живой это голос или
синтезированный (голосовой дипфейк). Назначение — сценарий «Родственник в беде»,
когда мошенник звонит клонированным голосом близкого человека.

- **Данные:** [RuASD](https://huggingface.co/datasets/lab260/RuASD) — 37 систем
  синтеза русской речи, корпуса живой речи, телефонные искажения
  (лицензия CC BY-NC-SA 4.0). Использованы 54 из 250 архивов, 119 250 записей.
- **Метод:** 182 акустических признака (LFCC, MFCC, спектральные, просодические) +
  градиентный бустинг (`HistGradientBoostingClassifier`, scikit-learn).
- **Результат:** точность 96,6% на известных генераторах (EER 0,034),
  92,8% на незнакомых генераторах (EER 0,062). Обучение — около 23 с на CPU.

## Файлы в `training/voice/`

### Данные

| Файл | Назначение | Основные функции |
|---|---|---|
| `map_ruasd.py` | Карта набора без скачивания: по HTTP (запрос Range) читает заголовок и метаданные первой записи каждого из 250 архивов и выбирает архивы так, чтобы были представлены все генераторы, корпуса живой речи и телефонные искажения. Результат — `data/ruasd/chosen_shards.txt` | `http_range`, `first_meta`, `probe`, `segments`, `choose` |
| `download_ruasd.py` | Загрузка выбранных архивов с Hugging Face с докачкой и проверкой свободного места; после загрузки запускает индексацию | `list_shards`, `pick_spread` |
| `index_ruasd.py` | Индекс всех записей прямо из tar-архивов, без распаковки: метаданные и заголовки WAV → `data/ruasd/ruasd_index.parquet` и сводка по составу | `wav_header`, `index_shard`, `summarize`, `print_report` |

### Обработка звука, признаки, метрики

| Файл | Назначение | Основные функции |
|---|---|---|
| `audioprep.py` | Чтение WAV, приведение к 16 кГц, обрезка тишины, нормализация громкости (−23 dBFS), фрагмент из середины записи, перевод в телефонную полосу 8 кГц | `read_wav`, `resample`, `trim_silence`, `normalize_rms`, `preprocess`, `center_crop`, `windows`, `to_narrowband` |
| `features.py` | 182 признака фрагмента: LFCC с первыми и вторыми разностями, MFCC, спектральные характеристики, просодия (частота основного тона, джиттер, шиммер, паузы, разброс громкости) | `power_spectrum`, `cepstrum`, `deltas`, `spectral`, `prosody`, `feature_names`, `extract` |
| `evalutil.py` | EER и порог, отчёт по выборке (accuracy, precision, recall, F1, ROC-AUC, матрица ошибок), разбивка по источникам | `eer`, `report`, `by_source` |

### Основной эксперимент (все записи, разбиение 70/15/15)

| Файл | Назначение | Основные функции |
|---|---|---|
| `train_full.py` | Признаки для всех записей (с кешем), разбиение 70/15/15 по исходной записи (запись и её искажённые копии — в одной выборке), обучение бустинга, порог по EER на валидации, метрики с бутстреп-интервалами, разбор по источникам и искажениям, отчёт. Эксперимент А — без флагов; эксперимент Б (10 генераторов и 2 корпуса отложены в отдельный тест) — флаг `--holdout` | `build_features`, `assign_groups`, `split_of`, `metrics`, `bootstrap`, `per_source`, `write_md` |
| `fullworker.py` | Расчёт признаков одного архива в отдельном процессе; результат сразу пишется на диск, поэтому прерванный расчёт продолжается с места остановки | `shard_job` |
| `predict_voice.py` | Оценка собственного WAV-файла обученной моделью: запись режется на окна по 3 с, вероятности синтеза усредняются | `score_file` |

### Предварительный эксперимент (шорткат, абляция, сравнение полос 8 и 16 кГц)

| Файл | Назначение | Основные функции |
|---|---|---|
| `prepare_ruasd.py` | Сбалансированные выборки train / val / test_seen / test_unseen / test_phone с отложенными генераторами и корпусами; фрагменты сохраняются в `data/ruasd/prepared/` | `waterfill`, `build_splits`, `process_shard` |
| `train_baseline.py` | Проверка на шорткат (модель только по частоте дискретизации и длительности файла), бустинг на признаках, абляция групп признаков (`--exclude`), выбор полосы (`--sr`) | `shortcut_check`, `feats`, `hgb` |
| `run_all.py` | Все прогоны предварительного эксперимента одной командой | `run` |
| `make_summary.py` | Сводный отчёт `reports/voice/summary.md` и `reproducibility.json` | `load`, `versions` |

## Запуск (Windows, PowerShell, из папки `training`)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# Данные: карта набора, загрузка выбранных архивов, индексация
.\.venv\Scripts\python.exe voice\map_ruasd.py
.\.venv\Scripts\python.exe voice\download_ruasd.py --list data\ruasd\chosen_shards.txt

# Основной эксперимент: А и Б (во втором запуске признаки берутся из кеша)
.\.venv\Scripts\python.exe voice\train_full.py
.\.venv\Scripts\python.exe voice\train_full.py --holdout

# Предварительный эксперимент
.\.venv\Scripts\python.exe voice\run_all.py

# Проверка собственной записи
.\.venv\Scripts\python.exe voice\predict_voice.py запись.wav
```

Если архивы лежат в другом месте, укажите путь параметром `--data-dir`.
Все случайные выборы зафиксированы (seed 42): на тех же архивах и версиях
библиотек повторный запуск даёт те же цифры.
